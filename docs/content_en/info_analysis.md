# 信息分析

## -info_defines

收集 design/verif 文件夹中的所有宏定义，分析指定层级内的文件夹/文件。
将创建 `info_defines` 来存储审查信息。该文件会被 git 忽略，需要手动删除。
请注意：vip 文件夹将被跳过。

审查信息包括：

- 在 design 中找到
- 在 verif 中找到

## -info_git_submodule

显示所有 git 仓库/子模块信息。

## -info_uvm

根据 `config/info/uvc.info` 中指定的列表，显示 xVCs 的文件/结构摘要。

## -info_all_testlist

test 文件夹中所有 testlist 的信息。

## 验证文档模板生成

UVE 支持为 IP 级和 SOC 级项目生成结构化的验证文档模板。生成的文档遵循标准化格式，涵盖所有核心验证规划要素。

**IP 级模板**包含：

- 作者及联系信息
- IP 概述与版本信息表
- 配置寄存器表
- 验证策略（方法、UVM 组件、参考模型、覆盖率策略）
- 调试说明
- 测试范围（功能特性表与 ASIC 验证检查清单）
- 回归测试与覆盖率签核

**SOC 级模板**包含：

- 作者及联系信息
- SOC 概述与版本信息表
- 前置步骤检查清单（环境准备、子模块验证）
- 所需工具列表
- 环境配置（子模块状态、库路径、VIP 版本）
- 验证策略（EDA 工具支持、流程支持）
- 验证计划（测试用例列表、SOC 测试台、SOC 场景、IP 级表格）
- 回归测试与覆盖率目标
- 签核检查清单
- 变更日志

生成的文档分别保存至 `doc/IP_Level/` 或 `doc/SOC_Level/` 目录下。
