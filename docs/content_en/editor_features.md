# UVE_EDITOR：完整功能范围

UVE_EDITOR 通过面向编辑器的工作空间提供 UVE 环境能力：

- 项目总览和路径配置；
- 子项目摘要和配置文件；
- design 文件夹、schematic、register 和 design 分析；
- filelist、文档、预编译设置和生成产物；
- 工具链状态和环境检查；
- 测试状态和表格分析；
- 回归状态、dashboard、报告、日志和重跑信息；
- 仿真摘要；
- package class、sequence、interface、define、parameter 和一致性；
- flow define、UVM 信息、testlist、寄存器模板和覆盖率模板；
- 源文件导航和可刷新的项目分析；以及
- 完整的集成式 User Guide。

扩展支持本地和远程工作区，为项目、设计、验证、分析和自动化视图提供统一导航入口。
