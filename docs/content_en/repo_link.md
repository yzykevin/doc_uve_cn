# 仓库符号链接管理

`repo_link` 用于在不同仓库之间建立项目目录的链接。当设计文件、验证环境、配置文件和文档位于独立的 git 仓库中，但需要在一个统一的项目结构下访问时，这个工具就能派上用场。它同时支持创建和清理这些链接。

## 适用场景

- 在多个项目间共享通用的验证 IP 或设计模块，避免文件重复
- 将独立的配置仓库链接到项目的配置目录中
- 将分离的设计仓库和验证仓库整合到同一个仿真工作空间
- 当某个被链接的仓库不再需要时，清理相关符号链接

## 支持的操作

### 创建链接

将源仓库目录中的符号链接创建到目标项目目录中，涵盖 design、verification、config 和 doc 等子目录。

### 清理链接

从目标目录中移除指向源仓库的符号链接，不会影响非符号链接的文件。
