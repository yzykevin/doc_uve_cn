# UVE_EDITOR：VS Code 项目探索与检查扩展

UVE_EDITOR 将 UVE 环境集成到 VS Code，提供面向项目的导航和检查工作空间。

## 项目和环境视图

- 项目总览和项目路径配置；
- 工具链和环境检查；
- 工具版本及工具状态；
- 子项目摘要和配置视图；
- design 文件夹、schematic、register 和 design 分析；
- filelist、文档文件、预编译配置和生成产物；以及
- 项目刷新和配置编辑。

## 验证视图

- 测试状态和测试表格分析；
- 回归状态、dashboard、报告、日志和重跑信息；
- 仿真摘要；
- UVM class、sequence、interface、define 和 parameter；
- package 及跨 package 一致性分析；
- flow define、UVM 信息、testlist、寄存器生成模板和覆盖率模板；以及
- 完整的集成式 UVE User Guide。

## 开发体验

扩展支持本地和远程开发会话、项目根目录自动发现、工作区项目路径覆盖、可刷新的分析、源文件导航和主题感知视图。
