# 报告服务器

报告服务器提供基于 Web 的仪表板，用于查看多个用户和项目的回归测试结果。

启动服务器后，可通过网页浏览器访问仪表板。

## 功能特性

- 聚合来自配置工作目录的回归测试结果
- 以颜色编码方式显示通过/失败/错误/跳过计数
- 定期自动刷新
- 支持按用户或状态筛选

## 配置

用户目录和服务器设置通过报告服务器 `config/` 文件夹中的 JSON 配置文件进行配置。

## 启动服务器

```terminal
python3 serve.py
```

## 选项

### --port / -p

监听的 TCP 端口。默认：`8765`。

### --host

绑定地址。默认：`0.0.0.0`。

### --config / -c

指定替代配置文件的路径。

### --debug

启用带热重载的调试模式。
