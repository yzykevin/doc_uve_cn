# 2.3 支持的仿真器系列

根据项目和已安装的许可证，UVE 支持集成：

- Synopsys VCS；
- Cadence Xcelium；
- Icarus Verilog；
- Verilator；以及
- 其他由项目配置的开源仿真器。

工具链将仿真器差异封装在项目工具流配置中，同时保留编译、执行、结果和调试等统一概念。

## Python 与 cocotb 验证

UVE 支持基于 Python 的 cocotb 和面向 pyuvm 的验证环境，包括测试模块选择、顶层选择、仿真器集成、随机种子处理、预编译、回归执行和结果收集。这样可以在 SystemVerilog 和 UVM 环境之外，同时使用 Python 验证方式。

## SVUnit 和单元级验证

SVUnit 工具流提供单元测试发现、测试脚手架、执行、清理和工作空间组织能力，适合维护小型、快速的 SystemVerilog 测试，并与更大范围的 UVM 及回归工具流互补。

## 回归和覆盖率

回归能力包括：

- 基于 testlist 的执行；
- 并行用例调度；
- VCS 和 Xcelium 回归变体；
- 失败用例收集和重跑；
- 开启波形的调试重跑；
- 通过/失败汇总；
- 结果检查分析；
- HTML 报告；
- 日志和用例导航；以及
- 面向磁盘空间的已完成结果清理。

在所选仿真器和项目配置支持的范围内，覆盖率能力包括常见的行、条件、翻转、FSM、分支、断言和功能覆盖率工具流。

## 形式验证、静态分析及变异分析工具流

UVE 为形式验证及相关分析提供项目入口，包括基于 JasperGold 的以下应用：

- 形式属性验证；
- 连接性和结构检查；
- 面向安全的分析；
- 时序等价性分析；以及
- 面向 lint 和质量的检查。

环境还支持 Certitude 相关的变异和故障分析工具流，包括文件列表生成、仿真器脚本和结果清理。

## 预编译与结果收集

公共预编译资产、生成的文件列表、已编译库、测试平台产物和工具相关运行产物都可以纳入项目工具流管理。验证和工具自检可以通过自动化测试执行，并使用基于 pytest 的方式收集和展示仿真、回归及工具结果。

## SoC 集成与自动连线

UVE 支持通过可复用设计和验证组件、可配置接口、项目元数据及自动连线辅助能力进行 SoC 级环境装配。这帮助团队以不同规模组合环境、连接常用模块和 wrapper，并从单个 IP 验证逐步扩展到集成子系统和 SoC 验证。

## 作业调度与报告

验证任务可以通过支持调度器的工具流连接到受管理的计算资源。UVE 提供 Slurm 和 LSF 集成模式，同时支持小型任务的本地执行。报告服务提供可搜索的测试、日志、结果、覆盖率信息和项目状态汇总。
