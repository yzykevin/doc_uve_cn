# UVE：通用验证环境

UVE 是面向硬件及半导体开发的私有项目验证环境。它将项目准备、仿真、回归测试、结果检查和可复用验证资产管理等常见工作组织在统一的工作空间中，帮助团队开展 IP、子系统及更大规模的硬件验证活动。

本页仅作产品能力介绍，不描述私有源代码、内部架构、仓库组织方式、实现方法、凭据或项目保密信息。

## UVE 提供的能力

- **面向项目的验证**：为 IP、子系统及更大规模的硬件验证活动提供一致的项目起点。
- **仿真工作流**：支持在兼容的商业及开源仿真器上开展常见的 SystemVerilog/UVM 和基于 Python 的验证工作流。
- **回归测试管理**：支持可重复的测试选择、执行、结果收集、失败重跑和汇总报告。
- **形式验证及静态分析支持**：在具备相应工具的环境中，为形式验证、连接性分析及相关检查提供组织化入口。
- **可复用验证资产**：提供共享库、验证包、测试平台辅助组件、接口、工具及验证组件。
- **测试平台辅助**：提供面向项目的测试平台文件和验证元数据创建、维护辅助能力。
- **寄存器及文档生成**：将结构化寄存器描述转换为常用的硬件、验证、软件及文档产物。
- **项目信息及报告**：以可浏览方式展示验证资产、文档、接口、参数、测试信息及一致性结果。
- **作业与资源集成**：支持将验证任务连接到本地或受管理的计算资源及作业调度系统。
- **开发者工具**：提供命令行工具、本地报告服务、仓库辅助工具和编辑器集成能力。
- **架构级建模**：提供独立的 UVE 架构能力，在详细 RTL 实现前支持硬件及系统架构的早期探索。
- **持续集成支持**：提供可复用的项目检查、验证任务自动化和持续集成构建模块。

## UVE 工具及配套产品

UVE 项目系列包含多个互相配合的工具。其具体实现和项目专用配置不属于本公开介绍范围。

### UVE 命令行工具

命令行工具集以统一方式提供项目信息发现、环境准备、验证任务启动、回归测试管理、报告收集、项目链接维护及生成文件管理等能力。

### UVE 信息浏览器

信息浏览器通过可搜索的本地 Web 界面展示验证包和项目元数据，帮助开发者查看类、序列、接口、参数、宏定义、文档及一致性信息，而无需手动搜索所有源文件。

### UVE 寄存器生成器

寄存器生成器接收结构化寄存器描述，并可生成选定的硬件、验证、软件头文件及文档产物。它用于减少重复的寄存器映射工作，并帮助保持相关产物的一致性。

### UVE VS Code 扩展

UVE VS Code 扩展将项目浏览和检查能力集成到编辑器中，提供项目总览、文档和文件列表导航、测试及工具信息、面向验证包的检查、刷新以及项目路径配置。它适用于本地和远程开发会话，主要视图不依赖单独启动的浏览器服务。

### UVE 架构平台

架构平台支持在 SoC 和 chiplet 系统上进行早期的软件化探索，帮助团队在详细 RTL 工作开始前分析系统结构、连接关系、地址空间、性能问题以及从架构到实现的交付。本文有意不公开专有组件细节和内部建模方法。

### UVE 项目指导

项目指导配套内容为维护者和开发者提供项目导览、约定、问题排查指导及验证流程参考。它用于补充通用验证知识，而不是替代通用方法论。

### UVE CI 及验证支持

UVE 提供自托管代码管理、持续集成、自动化检查、打包和项目级验证的可复用模式。具体部署设置和基础设施细节不在此公开。

## 适用用户

UVE 面向：

- 硬件及半导体验证工程师；
- RTL、IP、子系统、SoC 和 chiplet 开发团队；
- 结合 SystemVerilog、UVM、Python、cocotb、仿真和形式验证的工程师；
- 需要可复用验证基础设施、而不是零散脚本的团队；以及
- 希望通过命令行、浏览器或编辑器获得项目上下文的开发者。

## 公开文档边界

本网站仅在高层次介绍能力。私有实现细节、内部项目组织、保密产品信息、源代码、凭据、服务地址、专有算法、私有基准数据和项目专用验证数据均不在公开范围内。
