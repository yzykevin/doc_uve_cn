# UVE：通用验证环境

UVE 是面向 IP、子系统、SoC 和 chiplet 开发的硬件验证环境及工程工具链。它将可复用验证包、面向项目的自动化、仿真器和形式验证工具流、寄存器及测试平台生成、报告分析以及架构级建模组织在统一环境中。

## 验证环境

UVE 为以下工作提供统一的项目基础：

- IP 和模块级验证；
- 子系统及 SoC 集成验证；
- 可复用的 UVM 环境和验证组件；
- 基于 SystemVerilog、Python、cocotb 和 SVUnit 的测试；
- 仿真、回归、覆盖率、调试和结果分析；以及
- 早期架构与行为模型探索。

该环境既支持日常验证工作，也支持多个设计之间长期复用项目资产。

## 完整验证流程

UVE 将项目准备、设计和测试平台组合、预编译、仿真、回归、覆盖率、结果收集、调试和报告连接为一套可重复的完整流程。同一项目上下文可用于准备运行、选择测试、在本地或调度资源上执行、收集日志和产物，并通过终端、报告服务或编辑器视图检查结果。

该流程可从聚焦的 IP 验证扩展到子系统和 SoC 项目，并支持模块化项目组件、可复用示例、可配置工具适配器，以及根据项目需要增加或替换流程阶段。

## UVE 工具链

UVE 工具链通过面向项目的工具，统一组织主要验证活动。

### 项目准备与管理

- 项目初始化和环境准备；
- shell 环境设置与清理；
- 项目配置和工具流选择；
- 设计文件列表和测试文件列表管理；
- 仓库及子模块维护；
- 生成文件和工作空间清理；
- 项目一致性检查；以及
- 共享库和工具版本管理。

### 仿真工具流

仿真工具流覆盖硬件验证运行的主要阶段：

- 源文件和文件列表准备；
- 编译与 elaboration；
- 测试执行；
- 随机种子和重复次数控制；
- 波形生成及 GUI/调试模式；
- 功能覆盖率和代码覆盖率收集；
- 可配置的 DUT 和测试平台组合；以及
- 面向不同项目的可复用工具流配置。

### 支持的仿真器系列

根据项目和已安装的许可证，UVE 支持集成：

- Synopsys VCS；
- Cadence Xcelium/XRUN；
- Icarus Verilog；
- Verilator；以及
- 其他由项目配置的开源仿真器。

工具链将仿真器差异封装在项目工具流配置中，同时保留编译、执行、结果和调试等统一概念。

### Python 与 cocotb 验证

UVE 支持基于 Python 的 cocotb 和面向 pyuvm 的验证环境，包括测试模块选择、顶层选择、仿真器集成、随机种子处理、预编译、回归执行和结果收集。这样可以在 SystemVerilog 和 UVM 环境之外，同时使用 Python 验证方式。

### SVUnit 和单元级验证

SVUnit 工具流提供单元测试发现、测试脚手架、执行、清理和工作空间组织能力，适合维护小型、快速的 SystemVerilog 测试，并与更大范围的 UVM 及回归工具流互补。

### 回归和覆盖率

回归能力包括：

- 基于 testlist 的执行；
- 并行用例调度；
- VCS 和 Xcelium 回归变体；
- 失败用例收集和重跑；
- 开启波形的调试重跑；
- 通过/失败汇总；
- 结果检查分析；
- HTML 报告；
- 日志和用例导航；以及
- 面向磁盘空间的已完成结果清理。

在所选仿真器和项目配置支持的范围内，覆盖率能力包括常见的行、条件、翻转、FSM、分支、断言和功能覆盖率工具流。

### 形式验证、静态分析及变异分析工具流

UVE 为形式验证及相关分析提供项目入口，包括基于 JasperGold 的以下应用：

- 形式属性验证；
- 连接性和结构检查；
- 面向安全的分析；
- 时序等价性分析；以及
- 面向 lint 和质量的检查。

环境还支持 Certitude 相关的变异和故障分析工具流，包括文件列表生成、仿真器脚本和结果清理。

### 预编译与结果收集

公共预编译资产、生成的文件列表、已编译库、测试平台产物和工具相关运行产物都可以纳入项目工具流管理。验证和工具自检可以通过自动化测试执行，并使用基于 pytest 的方式收集和展示仿真、回归及工具结果。

### SoC 集成与自动连线

UVE 支持通过可复用设计和验证组件、可配置接口、项目元数据及自动连线辅助能力进行 SoC 级环境装配。这帮助团队以不同规模组合环境、连接常用模块和 wrapper，并从单个 IP 验证逐步扩展到集成子系统和 SoC 验证。

### 作业调度与报告

验证任务可以通过支持调度器的工具流连接到受管理的计算资源。UVE 提供 Slurm 和 LSF 集成模式，同时支持小型任务的本地执行。报告服务提供可搜索的测试、日志、结果、覆盖率信息和项目状态汇总。

## Design IP 库

UVE 包含持续扩展的可复用 Design IP 和集成示例库，用于为常见 SoC 功能提供一致的起点，并将这些功能同时提供给设计和验证工具流。

当前 Design IP 方向包括：

- always-on 和低功耗定时器功能；
- 通用定时器和 watchdog 功能；
- UART、SPI、I2C、GPIO、mailbox 和中断控制外设；
- 时钟、复位、电源管理和引脚复用支持；
- debug 控制、debug 状态、debug lock、JTAG 和 debug 总线访问；
- 错误管理及 firewall/访问控制功能；
- PMU 和 SoC 信息服务；
- AXI/APB bridge 及外设集成功能；
- NoC 管理及系统控制功能；
- boot-ROM 和启动支持；
- DSP 及部分 AI/NPU 相关模块；以及
- SoC 级集成示例和参考装配。

Design IP 库结合验证、寄存器描述、文档和集成支持进行开发，使模块能够作为完整项目的一部分进行评估，而不是孤立的源代码目录。

### 协议 IP 与可配置 wrapper

Design IP 方向包含面向 AXI4-Lite、APB 等接口的可复用协议模块和可配置 wrapper。通过 wrapper 配置，同一集成概念可以适配不同项目环境，而不需要每个项目重新构建周边基础设施。

## 可复用验证包

UVE 验证包库为常见验证关注点提供可复用的 SystemVerilog/UVM 基础设施，包括：

- base 和通用工具；
- environment 和 phase 管理；
- 时钟、复位、同步及引脚级支持；
- 中断处理；
- DMA 和存储器相关验证；
- 错误注入；
- 性能测量和报告；
- 对象池及可复用事务；
- 寄存器模型工具；
- 面向 AHB、APB、AXI、AXI-Stream、I2C、OCP、SPI 和 UART 的协议寄存器支持；以及
- 验证报告和共享辅助服务。

验证包库还配套提供可复用的 I2C、SPI 和 UART 协议验证支持，用于减少重复的基础设施开发，同时保持项目环境的灵活性。

### 验证 IP 与 VIP 方向

UVE 正在开发面向常用协议和接口行为的可复用验证组件及 VIP 库，目标是提供可配置的 agent、monitor、driver、scoreboard、sequence、协议检查和共享验证服务，并支持跨项目组合使用。

## 行为模型与架构模型库

UVE 包含架构级建模平台，用于在详细 RTL 实现前进行早期系统探索。该平台基于软件模型和事务级接口，使团队能够在合适的抽象层次研究系统行为、集成和性能问题。

模型和组件方向包括：

- RISC-V CPU 及处理器封装；
- 互连、crossbar、仲裁和 NoC 模型；
- 存储器及存储器控制器模型，包括 DDR 和 HBM 方向研究；
- chiplet 和 die-to-die 连接模型；
- PCIe、Ethernet、CXL 及其他高速连接抽象；
- UART、SPI、I2C、GPIO、timer、watchdog、RTC 和中断外设；
- 时钟和电源管理行为；
- security、root-of-trust、secure-boot 和访问过滤模型；
- telemetry 和事务观测组件；以及
- AI 加速器和 NPU 架构探索。

模型库支持拓扑探索、架构评审、性能研究、集成实验以及从架构工作向 RTL 开发的结构化交付。

架构工具流基于 SystemC 和 Accellera 生态技术，正在从组件级探索扩展到完整系统研究、软件可见行为、Linux 启动以及架构到 RTL 的验证。

## 寄存器与测试平台生成

UVE 提供将结构化描述转换为一致项目产物的生成工具。

### 寄存器生成

寄存器生成器支持 YAML、JSON、TOML 和电子表格等结构化输入，并可在配置支持时转换其他行业格式。它可以生成：

- UVM register-abstraction model；
- SystemVerilog 寄存器 RTL；
- 软件访问用 C header；
- Markdown 寄存器文档；以及
- 转换或规范化后的寄存器描述。

它支持常见总线配置、地址和数据宽度设置、数组、别名、间接寄存器以及丰富的字段访问行为。

### 测试平台和 UVM 生成

生成工具可辅助创建：

- DUT 和 HVL 顶层脚手架；
- 测试平台 include 文件和文件列表；
- testlist 模板；
- base test；
- UVM agent、environment、register 和 sequence library 模板；以及
- 项目配置格式转换模板。

这些生成器提供可重复的起点，同时将最终验证架构和实现控制权留给项目团队。

生成能力支持组合使用：项目可以将配置、测试平台、寄存器、覆盖率、Jasper、报告和统计分析产物，与手写的项目内容结合起来。

## 项目信息和分析

UVE 提供将项目元数据转换为工程视图和报告的工具。

能力包括：

- package 和组件发现；
- UVM class、sequence、interface、define 和 parameter 检查；
- README 和文档渲染；
- testlist 和测试状态分析；
- design 和 register 汇总；
- filelist 和配置检查；
- 工具及环境信息；
- 相关描述之间的一致性检查；以及
- 用于浏览项目信息的本地报告服务。

## UVE VS Code 扩展

UVE VS Code 扩展将项目探索和检查能力集成到编辑器中，提供：

- 项目总览和导航中心；
- design、子项目、filelist 和文档视图；
- 工具链和环境检查；
- 测试状态和回归视图；
- package class、sequence、interface、define、parameter 和一致性视图；
- register 和 design-analysis 视图；
- 项目配置编辑和刷新；
- 本地及远程开发支持；以及
- 完整项目操作参考所需的集成式 UVE User Guide。

## 持续集成与项目自动化

UVE 提供以下项目自动化能力：

- 源代码管理和代码评审工具流；
- 持续集成执行；
- 自动 lint、测试和打包检查；
- 可复现的工具及环境准备；
- 产物和报告生成；以及
- 项目级变更验证。

这些能力同时支持个人开发和团队级可重复验证。

CI/CD 环境基于 Forgejo 和 Woodpecker 工具流构建，用于支持多项目协作、自动验证、打包、产物发布和可重复的工程检查。

## 开发方向

UVE 持续开发中，当前方向包括更丰富的可复用 IP 和 VIP、更完善的行为及架构模型、更深入的寄存器与验证包集成、pyuvm 和 Python 工具流支持、更广泛的仿真器和形式验证工具支持、支持 Linux 启动的系统研究、更强的项目分析能力，以及更完善的编辑器工作流。
